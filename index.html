🎯 O que são Funções?

Na IA, funções são como receitas que transformam entradas em saídas. Elas são a base de todo algoritmo inteligente!

f(x) = y entrada → processamento → saída

🧮 Funções Matemáticas na IA

  • Função de Ativação Decide se um neurônio "dispara" ReLU(x) = max(0, x)
  • Função de Custo Mede o erro do modelo Erro = (previsão - real)²
  • Função de Perda Otimiza o aprendizado Cross-Entropy = -log(probabilidade)

🤖 Funções na Prática

// Função que simula um neurônio
function neuronio(entradas, pesos, bias) {
    let soma = 0;
    for (let i = 0; i < entradas.length; i++) {
        soma += entradas[i] * pesos[i];
    }
    soma += bias;
    return ativacao(soma);
}

// Função de ativação ReLU
function ativacao(x) {
    return Math.max(0, x);
}
